## 范围与状态定义

本清单覆盖小说数据、模型协议、自定义 HTTP Adapter、能力与 Route、DAG Workflow、上下文检索、人工审批与事务写回、备份恢复、安全加固、性能和 Windows 发布。

- `已验证`：已由本地自动化、真实浏览器流程、静态检查或既有桌面发布记录直接验证。
- `仅 Mock 覆盖`：应用行为已由本地 Mock/Fake Provider 验证，但未调用真实第三方模型服务。
- `未覆盖`：当前发布流程没有相应验证，不能据此作出保证。

## 桌面发布验证边界

2026-07-21 的既有发布记录曾验证打包程序自检、GUI 生命周期、安装/卸载/重装以及保留数据库后的启动。该记录不是当前提交上的重新认证；2.2.8 正式产物仍须在干净标签、全部 CI 与 Release 门禁通过后才能标记 GO。

当前安装包未使用商业代码签名；Windows SmartScreen 可能显示“未知发布者”。用户应从项目发布页获取产物并核对 `SHA256SUMS.txt`。

## 已知限制与未关闭项

- 产品只面向本机单用户 Windows 环境，不具备公网服务所需的 TLS、登录、租户隔离和分布式配额。
- SQLite、日志以及未设置密码的备份默认不加密；同一 Windows 账户下的软件属于本地信任边界。
- 自动化不调用付费或真实第三方模型 API，Provider 的可用性、账户权限、地区政策和响应格式不在本次结论内。
- Windows 商业代码签名、独立渗透测试、无障碍认证和长期压力测试尚未覆盖。
- 完整残余风险及操作限制见 `docs/KNOWN_LIMITATIONS.md` 与 `docs/SECURITY_AUDIT.md`。

## 结论

当前代码满足本机单用户 Windows 候选版本的发布门槛，但这不等于公网服务安全认证，也不代表第三方模型服务当前可用。正式安装包只有在干净标签构建和全部发布门禁通过后才可标记 GO。
